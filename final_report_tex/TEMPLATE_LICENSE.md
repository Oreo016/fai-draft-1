# LaTeX style attribution

`PRIMEarxiv.sty` is the single-column style from Moulay A. Akhloufi's Arxiv & PRIME AI Style Template. The Overleaf gallery lists the template under Creative Commons Attribution 4.0 International. The paper replaces the sample manuscript with Group 27's text and adapts the running header. The bundled style file is unmodified. [Overleaf template](https://www.overleaf.com/latex/templates/arxiv-and-prime-ai-style-template/qdnhqytdqzsc) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

The gallery exposes the template driver and requires an account to open the full template project. The bundled style came from two public mirrors that returned identical bytes. Its SHA-256 is `0b60acdaf6022bb253a646be487912faf398187301f5bb104dda870ea85accea`. [First mirror](https://github.com/keanteng/arxiv-latex/blob/main/PRIMEarxiv.sty) · [Second mirror](https://github.com/josearangos/Speech-separation-in-real-time-using-deep-learning-architectures/blob/main/PRIMEarxiv.sty)

Akhloufi's style adapts George Kour's arXiv style, which carries an MIT license. The original MIT notice is included. [Kour's arXiv style](https://github.com/kourgeorge/arxiv-style) · [MIT notice](LICENSE-arxiv-style.txt)
